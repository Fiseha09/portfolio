# 🛒 AlgoMage Commerce

AlgoMage Commerce is a full-stack e-commerce learning project designed to practice modern web development fundamentals, build core online store features, and refine Git/GitHub workflows.

---

## 🚀 Features & Learning Goals

- 📦 **Product Catalog:** Manage, display, update, and delete store items.
- 🛒 **Shopping Cart:** Add, remove, and update product quantities.
- 💳 **Checkout Flow:** Simulated checkout process and order summary.
- 🔐 **User Authentication:** Basic account creation and login workflow.
- 🚚 **Order Tracking:** Demo-level order status and management.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript *(Planning React / Vue integration)*
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / SQLite
- **Tools & Version Control:** Git, GitHub

---

## 📚 Purpose

This project serves as a hands-on sandbox to:
* Practice end-to-end full-stack web development.
* Understand architecture and database relationships in e-commerce applications.
* Master software engineering best practices and version control.
